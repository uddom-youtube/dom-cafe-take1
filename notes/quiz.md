# សំណួរតេស្ត ✍️
1. Git និង GitHub ខុសគ្នាយ៉ាងម៉េច?
2. `-u` ក្នុង `git push -u origin main` ធ្វើអ្វី?
3. `git clone` និង `git pull` ខុសគ្នាយ៉ាងម៉េច?
4. push key ពិតដោយច្រឡំ។ ជំហានទីមួយ?

## ចម្លើយ
1. Git = កម្មវិធី · GitHub = website ដែលរក្សា repository online
2. ចងចាំ origin/main · ក្រោយមក `git push` ទទេបាន
3. clone = លើកដំបូង ទាំងមូល · pull = commit ថ្មីប៉ុណ្ណោះ
4. Rotate key (បិទ key ចាស់) · រួចទើបលុបពី Git
