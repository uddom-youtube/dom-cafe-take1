# 5.3 remote · push
```text
git remote add origin https://github.com/<user>/dom-cafe.git
git remote -v
git push -u origin main     # លើកដំបូង
git push                    # លើកក្រោយ
```
- **origin** = ឈ្មោះហៅក្រៅ របស់ URL នៅលើ GitHub
- **-u** = ចងចាំ origin/main → ក្រោយមកវាយតែ `git push` · `git pull`
- push លើកដំបូង: Windows បើកផ្ទាំង sign in GitHub (Git Credential Manager) · តែម្តងគត់
- ឬ token: Settings → Developer settings → Tokens (classic) · scope `repo` · ចាត់ទុកដូច password
- ⛔ កុំដាក់ password ឬ token ក្នុង URL
