# 5.6 ⚠️ key · password · token
- push រួច = **សាធារណៈ** · bot ស្កេន GitHub រាល់នាទី
- លុប file ក្នុង commit ថ្មី ≠ លុបពី history

## បើ push ដោយច្រឡំ
1. **Rotate**: បិទ key ចាស់ · បង្កើត key ថ្មី (នៅ website ដែលផ្តល់ key)
2. `.env` ក្នុង `.gitignore` · `git rm --cached .env`
3. commit · push

## ការពារ
- `.gitignore` **មុន** commit ដំបូង
- `git status` មុន `git add .`
