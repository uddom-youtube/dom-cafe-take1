# 5.1 Git ≠ GitHub 🌍

| Git | GitHub |
|---|---|
| កម្មវិធី លើកុំព្យូទ័ររបស់យើង | website · server លើ internet |
| commit · branch · history | រក្សាទុក repository online |
| ធ្វើការបាន ដោយគ្មាន internet | ចែករំលែក · ធ្វើការជាក្រុម · backup |

```text
កុំព្យូទ័រ (local)          GitHub (remote = origin)
   main  ── git push ──▶   main
         ◀── git pull ──
```
- ផ្សេងទៀត: GitLab · Bitbucket (Git ដដែល)
